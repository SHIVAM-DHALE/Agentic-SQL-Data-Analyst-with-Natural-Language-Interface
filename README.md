
# Agentic SQL Data Analyst with Natural Language Interface

## Overview

This project enables users to interact with databases using natural language instead of writing SQL queries manually. The system converts user questions into SQL queries, executes them on the database, and presents the results in a user-friendly format.

## Features

- Natural Language to SQL Conversion
- AI Agent-Based Query Processing
- SQL Query Validation
- Database Interaction
- Data Visualization
- Automated Insight Generation

## Tech Stack

- Python
- SQL
- LangChain
- OpenAI / Gemini API
- Pandas
- Streamlit
- SQLite / MySQL

## Workflow

1. User enters a question in plain English.
2. AI Agent converts the question into SQL.
3. SQL query is validated and executed.
4. Results are retrieved from the database.
5. Insights and visualizations are generated.

## Example Queries

- Show total sales for 2025.
- List top 10 customers by revenue.
- What is the average order value?
- Show monthly sales trend.

## Future Enhancements
